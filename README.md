# 菩提心チャレンジシート（第2版） 再現Webアプリケーション

GLAの「菩提心チャレンジシート（第2版）」の座標軸・文字・枠線・透かし文字・イラストを忠実に再現し、全項目への文字入力・自動保存・ファイル保存・A4横印刷/PDF出力に対応したWebアプリケーションです。

---

## 🌟 主な特徴と再現ポイント

1. **原本に忠実な構造と完全再現**
   - **人の横顔シルエット**:
     - 顔の向きを原本通り「**右向き**」（カオス・受信側に向き合う）に完全修正。
     - 塗りつぶしを無くし（透過）、主張を抑えた上品で極めて淡いグレーの輪郭線として描画。
   - **4つの矢印の完全再現**:
     - 【左端（横矢印）】生まれた現実 ⇐ いつもの受発色＆新たな受発色（左向き ⇐）
     - 【右端（横矢印）】受発色 ⇐ 出会ったカオス（左向き ⇐）
     - 【発信側（縦矢印）】いつもの受発色（発信） ⇩ 新たな受発色（発信）（下向き ⇩）
     - 【受信側（縦矢印）】いつもの受発色（受信） ⇩ 新たな受発色（受信）（下向き ⇩）
   - **受発色の上下2段構造**:
     - 上段「**いつもの受発色**」：左（発信）／右（受信）を分けて入力可能。
     - 下段「**新たな受発色**」：上段と同じ配列で、左（発信）／右（受信）を分けて入力可能。
     - 上段と下段を分ける水平枠線を忠実に再現（矢印帯や余計なキーフレーズ枠は削除）。
   - **（発信）と（受信）の位置**:
     - 原本画像通り、中央エリアの最下部（枠の下の方）に「（発信）」「（受信）」を配置。
   - **透かし文字**:
     - 「受」（中心破線の上下2箇所）、「色」（右上・右下）、「発」（左下）、およびアクション/エクササイズ境界下の丸囲み「発」を完全配置。

2. **全枠への入力・編集対応**
   - **ヘッダー**: 「会員番号」「ターミナル」「氏名」枠
   - **出会ったカオス（事態）**: 右カラムの縦長枠に広々と記入可能
   - **いつもの受発色**: 「発信」「受信」の2枠に分けて入力可能
   - **新たな受発色**: 「発信」「受信」の2枠に分けて入力可能
   - **アクション**: 具体的な実践ステップ
   - **エクササイズ**: 心を整える習慣・日常の留意点
   - **（　　）の心の菩提心**: 心の名称（入力可能）＋「いかなる力を現したいですか？」
   - **生まれた現実**: 変化した現実、創り出された調和の結果

3. **充実の実用機能**
   - 💾 **自動保存機能**: 入力した内容はブラウザ（LocalStorage）に自動で即座に保存されます。ページを閉じても消えません。
   - 💡 **記入例（サンプル読込）**: どのようにシートを記入するか一目でわかる実践的な模範記入例をワンクリックで読み込み可能。
   - 📥 **ファイル保存（JSONエクスポート）**: 入力内容を「氏名＋日付」付きのJSONファイルとしてPCに保存可能。
   - 📤 **ファイル読込（JSONインポート）**: 過去に保存したファイルを読み込んで再編集・印刷が可能。
   - 🖨️ **A4横 印刷・PDF出力**: 余白やページはみ出しなしで、A4横1枚にぴったり収まる専用プリントスタイルを内蔵。
   - 🔍 **ズーム & 全体表示**: 画面解像度に合わせて等倍・拡大・縮小・画面フィットを自由に調整可能。
   - 🎨 **図の濃淡スライダー**: 背景のシルエットや透かし文字の濃さを自由にスライダーで調整可能。

---

## 🚀 使い方

1. フォルダ内の **`アプリを起動.bat`** をダブルクリックするか、**`index.html`** をお好みのブラウザ（Google Chrome、Microsoft Edge等）で開きます。
2. 各枠をクリックして文字を入力します。
3. 記入が終わったら、上部ツールバーの **「🖨️ 印刷 / PDF」** をクリックすると、A4横1枚で美しく印刷またはPDFとして保存できます。
